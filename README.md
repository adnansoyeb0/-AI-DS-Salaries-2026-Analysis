# 📊 AI & Data Science Job Salaries 2026 - Executive Dashboard & Analysis

## 📌 Project Overview
This project presents a comprehensive analysis of global compensation trends within the Artificial Intelligence and Data Science sectors for 2026. Using data-driven metrics, an interactive **Excel Executive Dashboard** and an **Executive Summary Report** were developed to evaluate key factors influencing Tech salaries.

---

## 🔑 Key Features & Insights Analyzed
* **Role-Based Compensation:** Analyzed average salaries across 9+ key positions including *Data Science Managers, LLM Engineers, AI Engineers, and Data Analysts*.
* **Experience & Education Impact:** Comparative breakdown of salary growth based on career levels (Entry to Executive) and degree levels (Bachelor's to PhD).
* **Work Arrangement & Company Dynamics:** Insight into salary variances based on remote work ratios (100% Remote, Hybrid, On-site) and company scale (Startups vs. Large Enterprises).
* **AI Tool Adoption & Sentiment:** Evaluated the correlation between weekly AI tool usage, compensation, and automation anxiety.

---

## 🛠️ Tools & Technologies Used
* **Microsoft Excel:** Data Cleaning, Formulas (`AVERAGEIF`), KPI Metric Cards, and Data Visualizations (Bar & Column Charts).
* **Data Analytics:** Data Aggregation, Trend Analysis, and Reporting.
* **Documentation:** Detailed Executive PDF Report summarizing workforce takeaways.
